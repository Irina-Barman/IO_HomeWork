1. Создать файл в именами. Все имена должны быть написаны в одну строку и между ними должен быть только пробел.

2. Прочитайте их и соберите в одну строку, испольщуя Reader и чтение в массив.

3. Полученную строку преобразуйте в массив имён. Используйте метод split из класса String.

4. Преобразуйте массив в stream, отфильтруйте оставив только имена которые начинаются с буквы А.

5. Выведите результат в консоль
